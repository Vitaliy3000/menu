# CLAUDE.md

## После каждого изменения — коммит и пуш

Каждое завершённое изменение в репозитории сразу коммить и пушь в `origin main`, не спрашивая подтверждения. Пуш в `main` сразу деплоит сайт на GitHub Pages, поэтому:

1. **Проверки.** Если менялись код, данные или схемы — перед коммитом `npm run check` (то же, что в CI). Падает — чини, сломанное не пушь. Для правок только в `.md` проверки не нужны.
2. **Только свои файлы.** Добавляй файлы явно по именам (`git add <path>`), никогда `git add -A` / `git add .`. Перед коммитом смотри `git status --short`: репозиторий публичный, а в папку попадают личные файлы (например, экспорт Telegram `result.json`). Всё, что похоже на личные данные или экспорт, не коммить и скажи об этом пользователю. Чужие незакоммиченные изменения, которых ты не делал, тоже не захватывай — спроси.
3. **Без подписи.** Коммиты и теги не подписываются (`commit.gpgsign = false` и `tag.gpgsign = false` в `.git/config`). Если git снова требует подпись — выставь это локально, глобальный конфиг не трогай.
4. **Сообщение.** На английском, как в истории: короткий заголовок, в теле — что изменилось и зачем.
5. **Пуш.** `git push`. Если отклонён — `git pull --rebase` и повтори. Force-push — только по прямой просьбе пользователя.
